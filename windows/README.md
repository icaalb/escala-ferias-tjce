# Atalho Windows — Escala TJCE\n\nEste pacote cria um atalho na Área de Trabalho para abrir o sistema institucional da intranet.\n\n## Arquivos\n\n- CRIAR-ATALHO-ESCALA-TJCE.bat\n- CRIAR-ATALHO-ESCALA-TJCE.ps1\n- escala-tjce.ico (ícone do sistema)\n\n## Uso pela TI\n\n1. Copiar a pasta windows para o computador do usuário.\n2. Editar a linha URL no arquivo BAT e substituir pelo endereço real da intranet.\n3. Executar CRIAR-ATALHO-ESCALA-TJCE.bat.\n4. O atalho "Escala TJCE - Férias" será criado na Área de Trabalho.\n\n## Implantação em vários computadores\n\nA TI pode distribuir o script por GPO ou ferramenta institucional de gestão de estações.\n\n## Navegador\n\nO script tenta Chrome, depois Edge e, por fim, o navegador padrão do Windows.\n
